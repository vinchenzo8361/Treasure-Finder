# Buried Treasure

A relaxing browser treasure-hunting game. Explore sandy islands, dig for coins and collectibles, upgrade your tools, and find the hidden treasure.

## Run locally

```bash
npm install
npm run dev
```

## Build static site

```bash
npm run build
```

Output is in `dist/` and can be hosted on any static host.

## Controls

- **WASD** / **Arrow keys** — move
- **E** / **Space** / **Click** — dig, pick up sand, enter shop, dispose sand

## Progress

Permanent collection, equipment, sand capacity, money, and Trophy Room runs are saved in `localStorage`.
